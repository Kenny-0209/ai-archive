# AI 자료 아카이브

AI 스킬, 디자인 참고 사이트와 게시물을 검색할 수 있는 정적 웹사이트입니다. `index.html`, `style.css`, `app.js`, `data.js`를 같은 위치에 두고 정적 호스팅에서 제공하면 됩니다.

검색·분야 필터·상세 보기와 브라우저에 저장되는 즐겨찾기를 지원합니다. 카드의 확인 수준은 원문 확인, 게시물 설명, 제공 설명, 후보 연결 등을 구분합니다. 스킬 모음은 여러 개별 스킬을 포함하므로 카드 수는 실제 스킬 총수와 다릅니다. 원문과 자료는 2026년 11월 16일 기준으로 정리되었습니다.
