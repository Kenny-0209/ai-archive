# UI 동작 사례

2026년 11월 16일에 정리한 Origin Kit 사례를 검색하고 원본 시연에 접근하는 공개 카탈로그입니다. 기존 AI 자료 아카이브의 첫 화면에서 이 페이지로 이동할 수 있습니다.

- `index.html`은 검색, 분야 필터와 사례별 미리보기 창을 제공합니다.
- `catalog.js`는 사례 이름, 분류, 태그, 원본 주소와 공식 시연이 있는 경우 해당 주소를 담습니다.
- `motion.js`는 시연 영상이나 체험 화면을 사용자가 열었을 때만 불러옵니다. 최초 화면에는 영상 플레이어와 iframe을 생성하지 않습니다.

영상과 체험 화면은 Origin Kit에서 제공하며 인터넷 연결이 필요합니다. 원본에서 외부 페이지의 표시를 막거나 리소스를 내리면 원본 주소로 이동해 확인할 수 있습니다. 이 폴더에는 공급자의 컴포넌트 소스 또는 전체 페이지 응답을 포함하지 않습니다.
